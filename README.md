# FreeGeo VPN

Free, cardless, general-purpose Android VPN with a community-grown pool of exit
nodes. Designed for bypassing internet restrictions, accessing region-locked
content (Discord, Telegram, X, Play Store) and general browsing — at **$0/month,
no credit card anywhere**.

## How it works

```
Android client (Kotlin/Compose + libXray)
  └─ VpnService + Xray-core (full-tunnel by default)
       └─ Exit node (VLESS+Reality or VLESS+WS+TLS)
            └─ Cloudflare WARP outbound (userspace WireGuard, per-node toggle)
                 └─ Internet

Node registry = static JSON published via GitHub Pages
  └─ built hourly by GitHub Actions health-checker
```

- **Nodes** run Xray-core with an optional WARP chain. Backbone nodes are on
  cardless free hosts (Serv00 Warsaw, CT8 Germany, Koyeb FRA). Community nodes
  are volunteer-run (SE Asia priority: MY/TH/ID/VN/PH, then BR/IN/etc).
- **Registry** (`registry.json`) is generated by `registry/generate.py`, which
  health-checks every node and disables it after 3 consecutive failures.
  Published to GitHub Pages; the app fetches and caches it.
- **Client** is full-tunnel by default with leak hardening (in-tunnel DoH,
  IPv6 capture, kill switch). Split-tunnel (app bypass + domain routes) is
  optional.

## Repository layout

```
freegeo-vpn/
├── registry/            # schema, seed nodes, health-checker/generator
├── .github/workflows/   # GitHub Actions (health-check, keep-alive, APK builds)
├── nodes/
│   ├── serv00/          # FreeBSD deploy script (VLESS+Reality + WARP)

```

## Quickstart

### Run the health-checker locally

```bash
cd registry
pip install -r requirements.txt
python3 generate.py --seed seed.json --output registry.json
```

### Deploy your own node

| Host | Command |
|---|---|
| Serv00 | `bash <(curl -fsSL <raw-url>/nodes/serv00/deploy.sh)` after enabling *Run your own applications* |
| Any Linux VPS/server | `bash <(curl -fsSL <raw-url>/nodes/community/bootstrap.sh)` |

See `docs/community.md` for the volunteer guide.

### Build the Android app

APKs are built automatically by GitHub Actions (`build-apk.yml`) — download the
artifact from the Actions tab and sideload it. For local command-line builds on
low-RAM machines, see `client/android/README.md`.
